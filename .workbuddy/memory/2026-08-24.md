## Gate 1b 缺口路线图（docs/tasks/gate-1b-gap-roadmap.md，新落盘）

- 用户问「Gate 1b 没有做的部分怎么办」，基于前几轮上下文（诚实清单 7 项缺口 + 批判定位修正）直接给策略判断，未改代码。
- 核心框架：7 项缺口按「做了构成差异化吗 + 该我们自己碰吗」两问分三类——A 该做（H2 结算 feed 技术验证 / H3 敏感性分析主战场）、B 轻量补不硬做（收款工具层 B8 参数修正、固定成本诚实标注、多平台 recipe 按需）、C 不该自己做（现金流管理/批次 FIFO/ERP OAuth，走中间路线不硬碰）。
- 关键判断：诚实标注「没做什么」本身就是产品价值——边际贡献不是净利润、COGS 是用户输入均值、不碰现金流管理，比硬塞不准的引擎更值钱。缺口不是欠的债，是「该不该自己做」的选择题。
- 优先级：① H3 敏感性分析 → ② B8 参数修正+固定成本诚实标注 → ③ H2 Settlement feed → ④ 多平台 recipe 按需 → ⑤ C 类不做诚实标注。
