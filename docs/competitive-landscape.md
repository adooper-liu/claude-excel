## 0. 一页结论

1. **品类已被验证**：Excel AI 加载项 + 侧边栏 agent 是真实市场（Melder 拿了 YC、OpenAI 官方进了场、第三方 GPT for Work 号称 700 万装机——B 级信源）。
2. **品类已分层，三层各有格局**：
   - **通用 AI 能力层**：Copilot Agent Mode / ChatGPT for Excel / Claude for Excel / GPT for Work——红海，且三家官方产品**全部要求表体上云**（Copilot 还强制 OneDrive AutoSave）。
   - **报告/呈现层**：Ada.im / Excel Dashboard AI / Bricks——拥挤，一次性使用为主（Excel Dashboard AI 流量下滑佐证），数字不可复核。
   - **口径管理 / 对账 / 审计 / 行业纵深层**：**扫完 10 个产品 + 三大官方插件，无人**。关键词全是 generate / visualize / report / sync，没有任何产品做「两个数据源核对差异并解释差异」。
3. **我们的位置就在空位层**：行业纵深（Pack 生态 + 跨境业财闭环）+ 结构性数据本地（127.0.0.1 本地后端，架构保证而非承诺）。
4. **对照卖点（对外可直接用）**：BYOK（成本=自己 API 账单）vs 订阅 credit 制（$50–200/月、超限即停）；写格单通道 + sourceHash 审计 vs 模型即兴洞察无审计；「你敢把全部店铺利润表上传到陌生网站吗」vs 云端 SaaS。

## 3. 值得抄的两点（产品借鉴）

1. **单元格级 AI 公式是漂亮的 UX 创新**（`=M.EXTRACT` 等）——AI 能力下沉到公式层，用户在既有工作流里组合调用，不依赖对话回合。本项目 `write_formula` 算子具备类似条件（如把假设分析做成可复用公式格），**记录为候选，不进当前优先级**。
2. **「上传文档进单元格再查询」降低门槛**——用户不需要理解 RAG。与本项目 connector 导 CSV 思路一致，方向已对齐。

**来自 §1.4 扫描的补充**：Ada.im 用户评价佐证「不只给数字，还要解释数字什么意思」的付费意愿——价值 brief 能力 C（三段式人话结论）方向得到外部验证，但我们的版本建立在活公式 + 审计行上（叙事学它，可验性打它）。

## 4. 值得打的两点（对外叙事直接用）

1. **credit 制 + $50–200/月是真实痛点**：分析到一半额度用完、月费与用量不匹配。对照话术：「BYOK——成本就是你自己 API 账单，多用多付，不用不付。」
2. **零行业深度**：Melder 无对账、无口径管理、无审计。Ada.im / Excel Dashboard AI 的洞察是模型即兴生成、数字不可复核。跨境业财是空白领地——正是 H1/H3 主场。

**来自 §1.4 扫描的补充**：对云端 SaaS 的对照话术——「你敢把全部店铺的利润表上传到一个陌生网站吗？」（Excel Dashboard AI 注册地安圭拉、数据全上云；官方三件套同样要求表体上云。）

## 5. 战略判断（v2，按品类扫描校准）

**竞争窗口判断更新**（替代 v1「窗口在收窄」）：

- **通用层窗口已关死**。Copilot Agent Mode GA + ChatGPT for Excel + Claude for Excel 三家官方全部进场，且第三方 GPT for Work 700 万装机。订阅制通用工具（Melder 模式）会被两面挤压（上有官方，下有开源 Sylvian），不追。
- **纵深层窗口还开着，且是空位**。扫完 PH「Excel AI」10 个产品 + 三大官方插件：**没有任何产品做「对账」（两个数据源核对差异并解释差异）**。空位的原因是要做对账+口径就得啃行业脏数据——Gate 1b 的 12 类脏数据 fixture + 三层匹配算法已经啃完，这是护城河不是负债。
- **相邻赛道已有人占，但形态不同**：Receiptor AI（云端 AI 记账）、Coefficient（SaaS 数据管道）方向对、形态不撞；不正面打数据同步（那是 Phase 2 connector 的活，走「用户导 CSV 喂进来」的轻路线）。

**差异化三条不变，各有对照物反证**：
1. **BYOK**——官方三件套 + Melder + Ada.im 全部绑自家模型/订阅，没人给中立模型选择。
2. **架构级本地**——官方三件套要求表体上云（Copilot 强制 OneDrive）、Excel Dashboard AI/Ada.im 数据传云端；明算是结构性不出机器，不是承诺。
3. **Pack 行业纵深**——全场只有通用模板，没人做行业口径包 + 用户自造分享（L3/L4）。

**行动**：在 ChatGPT for Excel 全面铺开（当前美加澳 beta）前，用知无不言实操帖拿种子用户（对应 Gate 1b 通过标准「1 个真实用户独立跑通」）。对外叙事主打空位层：「算得对 + 说得清 + 可复核」，不与通用层比拼模型能力。

### 5.1 痛点矿实证（2026-08-25，知无不言 Amazon 板块全量扫描）

发布策略的种子用户假设（ACOS 失控 / 退货政策焦虑帖）已用社区数据实证。抓取 Amazon 板块全量 437 页，关键词（对账/结算/回款/ACOS/退款/退货，含英文）预过滤入库，命中矿 **1268 条**（A 级=直接抓取观察；标题级信号，未抓正文；数据源 `tmp/wearesellers-scraper/`）：

| 关键词 | 命中帖 | 高热度(回复≥50) | 对应场景 |
|---|---|---|---|
| 退货 | 450 | 6 | H3 退货率敏感性 |
| ACOS | 364 | 22 | H1 净利核算 |
| 退款 | 253 | 6 | H3 退款/政策焦虑 |
| 对账 | 160 | 1 | H1/H2 对账 |
| 回款 | 99 | 6 | H2 结算回款 |
| 结算 | 20 | 0 | H2 结算拆解 |

三条种子画像全部有高热度实证帖：

1. **ACOS 失控**：「这个月的 acos 上升，单量下降，做了两年的老品越来越差」（127 回复）／「广告预算加了 ACOS 飙升不出单」（110 回复）——H1 净利核算入口。
