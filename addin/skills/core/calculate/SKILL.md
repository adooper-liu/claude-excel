# calculate

用还活着的公式算。源表只读；汇总值禁止写死。

| op | 用户怎么说 | 写出什么 |
|---|---|---|
| `lookup` | 按订单号把金额匹配过来 | 新表里 `INDEX` + `MATCH`（精确匹配，不依赖 XLOOKUP） |
| `sumifs` | 按类别求和 | 新表里 `SUMIFS`，合计会随源表变 |
| `fix_ref` | 修 #REF! | 新表去掉公式里的 `#REF!` 参数 |

必须先是 Excel Table（`ensure_table`）。空工作簿或没有带表头的表时，先问要不要生成样例，不要报错结束。透视走 /透视。

## 写公式时

- 查找默认 `INDEX`/`MATCH`，分类汇总默认 `SUMIFS`，容错用 `IFERROR`。不要把心算或脚本算好的数字贴进单元格。
- 分母可能为 0 时写成 `IF(分母=0,"",分子/分母)`，不要直接相除。
- 工作表名不是纯英文下划线时，跨表引用必须加单引号：`='假设输入'!$B$5`。
- 合并单元格只写左上角。
- 写完用 `inspect_formulas` 抽查 2–3 个格子，确认引用的是当前表头。
- `#REF!` 用本技能的 `fix_ref`；其它错误先 `scan_formula_errors` 报告位置，不要瞎改。
