# Chrome 扩展：当前页抓到 Excel

给**要登录、有验证码、反爬**的三方站用。扩展常驻在页面里：监听本页接口 JSON，也能点选/框选 DOM。数据只送到本机 Excel，不进模型。

不是搬任何商业选品插件的源码。能力对齐的是「打开页面就能收表」，站点不限。

## 安装

1. 启动本机后端（`launch.bat` 或 `python backend/server.py`），控制台里应出现 `http://127.0.0.1:8766`
2. Chrome 打开 `chrome://extensions`，打开「开发者模式」
3. 「加载已解压的扩展程序」，选仓库里的 `extension` 文件夹
4. Excel 里打开任务窗格
5. 若已装过旧版，必须点「重新加载」，并刷新已打开的报表页

## 用法

打开已登录的报表页。右下角出现 **取数**：

1. 在网页里筛选、搜索、翻页（和平时一样点）
2. 面板里会出现「接口表」（行×列）。点 **写入**
3. 任务窗格开着就会落表。翻下一页再点 **追加**

没有接口表时，再点「点选」或「框选」。点选会拦住页面点击，翻页前切回「浏览/翻页」或先收起。
