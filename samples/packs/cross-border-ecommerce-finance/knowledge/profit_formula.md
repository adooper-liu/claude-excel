# 利润假设模型（行业参考区间 · 非精确基准）

> ⚠️ 本文件所有数值均为**行业公开区间或官方定义**，不含任何伪精确个案。
> 任何单点精确值（如"佣金率 12.3%""ACoS 健康值 27%"）必须由**用户参数 sheet** 提供。
> 本文件仅供 assumption.py 读取默认值与标注阈值，不参与 LLM 自由生成。

## 一、净利润公式（FBA 卖家通用口径）


净利 = 订单本币 × 汇率
     − COGS（采购成本 + 头程均摊）
     − 平台佣金
     − FBA 配送费
     − 仓储均摊（月度）
     − 广告花费（从 Advertised Product Report 按 SKU+日期归集）
     − 支付手续费
     − 退款预估
     − 其他均摊（贴标 / 软件订阅 / 外包等，按量摊或固定月均）


### 各成本项说明与默认参数

| 成本项 | 公式位置 | 默认值 / 区间 | 数据来源 | 备注 |
|--------|---------|-------------|---------|------|
| 汇率 | 参数 sheet | 用户填写（如 7.2） | 用户 | Phase 1 固定汇率；Phase 2 支持按日期取汇率 |
| COGS | 参数 sheet | 用户按 SKU 填写 | 用户 | 若为空 → 标黄不阻断，毛利仍可算 |
| 平台佣金 | 参数 sheet 或默认 | **8%–15%（多数类目 15%）** | 亚马逊官方费率表 | 服装 17–20%；默认值建议 15% |
| FBA 配送费 | 参数 sheet 或默认 | **小标准件 ~$3.22–$3.65**（2026） | 亚马逊 FBA 价目 | 加 4/17 起燃油附加 **履约费 × 3.5%** |
| 仓储均摊 | 参数 sheet 或默认 | **$0.78–$2.40 / cu ft / 月**（淡季） | 亚马逊月度仓储费 | 旺季（Q4）上浮 2–3 倍 |
| 广告花费 | 自动从 Pack_Ads 读取 | 按 SKU+日期归集 | Advertised Product Report | 归因窗口见第三节 |
| 支付手续费 | 参数 sheet 或默认 | **2%–3%** | 跨境收款商惯例 | 连连/ PingPong / 万里汇等 |
| 退款预估 | 参数 sheet 或默认 | **退款率 5%–10%（服装 10%–20%）** × 单件毛利 | 行业白皮书均值 | 见下方退款计算规则 |
| 其他均摊 | 参数 sheet | 用户自定义 | 用户 | 可为 0 |

### 退款计算规则


退款预估 = 退款率（区间默认 5%–10%）× 单件毛利
         × 对应 SKU 的订单行数（含 platform_status=refunded / partial_refund 的行）


- 若订单表 `refund_amount` > 0，优先使用实际退款金额，不套公式
- 若 `refund_amount` 为空且 `platform_status` 含退款标记 → 用默认退款率估算
- 若 `platform_status` 为 completed → 不计算退款

## 二、广告效率指标（仅标注，不反推，不决策）

以下指标由 assumption.py 从广告数据算出，写入结果 sheet 的**辅助列**，用于条件格式标色。

| 指标 | 公式 | 标注规则 | 数据来源 |
|------|------|---------|---------|
| CTR | clicks / impressions | < 0.3% → 标黄 | 广告报表原生列 |
| CPC | cost / clicks | 高于品类均值 → 标黄（品类均值由用户参数 sheet 填） | 广告报表原生列 |
| ACoS | cost / attributed_sales | > 广告前毛利率 → **标红**；否则正常 | 广告报表原生列 |
| TACOS | cost / 总销售额（订单表） | > 15% → 标黄；8–15% 正常 | 广告花费 ÷ 订单总额 |
| ROAS | attributed_sales / cost | < 2 → 标黄 | 广告报表原生列 |

### 关键定义（来源：亚马逊 Advertising Help Center）

- **ACoS** = 广告花费 ÷ 广告归因销售额
- **TACOS** = 广告花费 ÷ 总销售额（自然 + 广告）
- **盈亏平衡 ACoS** = 广告前毛利率（即扣除所有非广告成本后的利润率）
- 判断广告是否亏损：**ACoS 必须低于广告前毛利率**，否则每单广告都在亏钱

> 行业参考：TACOS 健康观察带 **8%–15%**（Helium 10 / 行业复盘共识）；ACoS 常见运行区间 **20%–35%**，是否盈亏看是否低于该产品广告前毛利率。
> **本 Pack 不生成"你的 ACoS 应该调到 X"之类的建议。**

## 三、归因窗口声明（必须写入审计行）

| 广告类型 | 归因窗口 | 归因模型 | 报表 date 列含义 |
|---------|---------|---------|----------------|
| SP（商品推广） | **7 天** | 末次点击 | 点击日 |
| SB（品牌推广） | **14 天** | 末次点击 | 点击日 |
| SD（展示型推广） | **14 天** | 末次点击（+ 浏览） | 点击/展示日 |

**Phase 1 JOIN 策略**：
- 主键：`sku`（归一后）
- 日期：宽松窗口 `订单日期 ∈ [广告日期−3天, 广告日期+3天]`
- 审计行必须包含以下文字：


广告花费按报表点击日归集，与订单成交日存在 ≤7 天归因偏移（SP 默认 7 日末次点击归因）。
净利为近似口径，Phase 2 将支持按归因窗口参数精确对齐。

## 五、禁止项（本 Pack 铁律 · 防 AI 虚幻）

以下内容**严禁**出现在本文件、SKILL.md、assumption.py 输出或 LLM 对话中：

1. **禁止伪精确数**：不得出现"服装退款率应为 11.3%""ACoS 健康值是 27%"等无来源单点精确值。所有费率只以**区间**呈现（如 8%–15%）。
2. **禁止个案冒充基准**：不得引用任何具体卖家/公司的内部数据（如"某深圳卖家 17 个 SKU 亏损"）作为通用默认值。
3. **禁止反推合理值**：不得根据 CTR/ACoS 等指标反推"你应该把出价调到 X""建议否定此关键词"。
4. **禁止无证据归因**：差异分析不得用"汇率精度累积""浮点误差""已知行为"等无证据解释搪塞。
5. **禁止 LLM 心算毛利**：所有利润数字必须来自 `assumption.py` 的输出，LLM 不得在对话中直接计算或估算金额。
6. **知识来源标注**：若未来本文件引用某白皮书/工具商数据，必须标注"据 XX 白皮书/文档"，不得伪装成独立审计结论。

> 违反以上任一条，视为 Pack 校验失败，停止输出并报告用户。
