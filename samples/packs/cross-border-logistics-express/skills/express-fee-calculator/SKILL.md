# 快递费计算器（跨境物流场景）

本工作簿已有 **_规范 价目表**（基础运费 + 附加费表：尺寸超标 / 重量超标 / 大件 / 超大件 / 住址 / 偏远 / 操作）时，按内置 **calculator** 技能的「解读 → 建模 → 适配 → 验证」顺序建计算器。**通用公式约定**（概率折算、燃油只按基础、加权分区+下限、单调性检查）在核心 calculator 技能里，本技能只补**快递费场景**的识别清单与口径，不重复通用公式。

## 禁止

- ❌ 反复 `read_range` 读整张价目表（万行/多表会失败且不进模型）
- ❌ `write_to_sheet` 粘贴算好的运费数字
- ❌ 编造列名或费率；列名必须来自 `inspect_table`
- ❌ 跳过解读直接写公式——先讲清「基础按什么键、附加费怎么触发」

## 解读（快递费场景要看什么）

1. **inspect_workbook** 确认 _规范 表名与位置；对每张价目表 `ensure_table` → `inspect_table`。
2. 识别：
   - **基础运费表**：键列（计费重+分区？单键？）升序？有无**区域占比/权重列**？有无**折后最低价/下限**？
   - **附加费表**（每张一条）：触发列（重量/长/宽/高/周长/档位）、金额列、**概率列**（有则折算=金额×概率）、最低计重/起收、住宅/商业变体。
   - **燃油/比例项**：方案声明燃油费率 → 只按基础计收。
   - **费率单调性**：想核验就写检查公式 `=IF(本档价<上一档价,"倒挂","")` **只读 flag**；倒挂 → 红字提醒，不自动纠错。
3. **search_knowledge** `快递费 计费重 附加费 概率 加权`（若已装 pack 知识）— 口径见 `fee-calculator-appendix.md`。
4. 整理成一句定价模型描述讲给用户（如「基础费按 计费重+ZONE 查表，含概率折算附加费，燃油 25% 只按基础」）。

## 建模与适配（按核心 calculator 配方执行）

- 输入假设格：长/宽/高、实重、**体积系数**（单位口径见附录，写进假设格可改）、分区（含「加权平均」）、地址类型、燃油费率%。
- 中间量：体积重、计费重 = `CEILING(MAX(实重,体积重),1)`。
- 费用项：基础运费 + 每张附加费表一条 + 燃油（若声明）+ 合计；倒挂/超上限红字。
- 批量试算：首行公式 `fill_range` 向下填。
- 格式：输入格蓝字、关键假设黄底、倒挂/超限红字；分区/地址类型 `data_validation` 下拉。

## 验证与报告

- `scan_formula_errors` 扫计算器 sheet 确认无 `#REF!` / `#N/A`。
- 报告输入区地址、引用的 _规范 表与各费用公式位置、解读结论（含倒挂/超限）；提醒改尺寸/分区/地址类型即重算。

## 试跑口令

- `/快递费 根据基础运费和附加费表，生成计算器`
- `帮我做快递费计算器，任意尺寸、任意分区都能算`

## 边界

- 🟡 附加费表列结构与附录不一致：以 inspect 为准，公式用真实列名；匹配不上标 🟡 请人确认触发列/金额列/概率列。
- 🟡 倒挂/超限是提醒不是自动纠错：计算器只标红字，是否改费率表由人决定。
- 🔴 价目表不在本簿：引导用户先 `/整形` 或导入，不要编造价目。
