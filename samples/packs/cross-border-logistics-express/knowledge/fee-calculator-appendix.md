# 快递费计算器 — 跨境物流场景口径附录

供 `/快递费` 技能与知栏检索。数字以用户工作簿内 **_规范 表**为准，本文只列**快递费场景**的识别口径，不编费率；通用公式约定（概率折算、燃油只按基础、加权分区+下限、单调性检查、验证）见内置 calculator 技能，不重复。

## 单位与体积系数（假设格，可改）

| 场景口径 | 体积系数 |
|---|---|
| 厘米 + 千克（cm/kg） | 6000 |
| 英寸 + 磅（in/lb） | 250 |

体积重 = 长×宽×高 ÷ 体积系数；计费重 = CEILING(MAX(实重, 体积重), 1)。

## 快递费附加费识别清单（每张 _规范 表一条活公式）

| 类型 | 触发量 | 注意 |
|---|---|---|
| 尺寸超标 | 最长边 / 周长 / 三边 | 常带最低计重门槛 |
| 重量超标 | 毛重 / 计费重 | 常带最低计重门槛 |
| 大件超标 | 最长边 / 周长 | 有住宅/商业变体 |
| 超大件 | 超上限（长边/周长/毛重） | 常为统一价，触发即计 |
| 家庭住址费 | 地址类型 = 住宅 | 概率附加费，折算 = 金额×概率 |
| 偏远地址费 | 是否偏远 | 住宅/商业/Extend/Remote 多档 |
| 操作超标 | 操作动作 / 档位 | 概率通常低 |

- 概率列存在 → 折算成本 = 金额 × 概率。
- 地址类型变体 → 输入区加「地址类型」下拉，按类型取值。
- 燃油费率（若方案声明）→ 假设格，只按基础运费计收。

## 边界

- 多行批量测算：首行公式 `fill_range` 向下填充。
- 价目表更新：只改 _规范 源表，计算器自动重算。
- 时区 / 币种：只做运费数值；币种列若存在，合计旁标注「用户提供 / 待验证」。
