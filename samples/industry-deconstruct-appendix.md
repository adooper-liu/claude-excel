## 前三页市场格局（验证锚点）

分析前纪律：去广告 → 按页序重算 organic_rank；SERP 空的 brand/上架日等须外部补全或标缺失；月销缺失记 imputed。

**A 竞争格局（15）**：页流量占比、自然位集中度、价带分布、评论/评分分布、变体覆盖、品牌/卖家集中度、配送方式、类目分布。

**B 进入门槛（13）**：Top10 评论门槛、价格 P25/P50/P75、BSR 门槛、利润率/FBA/佣金分布、上架时间、新品占比。

**C 趋势生命周期（10）**：月销量趋势、BSR 波动、生命周期阶段、价量离散度。

🟢 可用现有算子：inspect → reshape_table(project) 规整列 → create_pivot 切片。

🟡 需第三方补全的深度字段、38 维全量聚合：人判是否值得买数据。

🔴 自动翻页回放、登录验证码：人工。

## 利润核算 11 项（假设格 + 活公式，不编费率）

净利润 ≈ 售价 − 采购 − FBA − 佣金 − 广告 − 预期退货损失 − 仓储 − 入库配置 − 头程。

🟢 write_inputs 写汇率/头程/退货率/广告 TACoS 假设；calculate_table 写活公式到新表。

🟡 售价取正常 Buy Box（非 Deal）；类目级退货率/ACoS 须标注「niche 级非 ASIN 级」。

🔴 外部货源/竞品拉数：用户自备数据或人工导入后再算。

## 评论 VOC 六维（纯表格输出）

固定六表，每维 TOP 20：①人群特征 ②使用场景 ③好评点(4-5星) ④差评点(1-3星) ⑤未满足需求 ⑥购买动机。

🟢 用户导入评论表 → inspect → extract_selection 按星级分列 → 新表汇总（表体不进模型）。

🟡 主题归类、占比计算：模型归纳，须标注样本量。

🔴 自动抓评论：取数栏 + 外部工具，不进核心 API。

## 竞品监控清洗规则（异常检测前必做）

- 时间对齐；缺失标 is_imputed。
- 评分数大降但星级几乎不变 → 降级为「评论清理」，非差评爆发。
- 销量归零但 BSR 仍在 → 「数据延迟」。
- Deal 与 Buy Box 分开算价变；禁止跨数据源混算趋势。

🟢 reconcile_tables 对两期快照；sort_filter 看异常行。

🟡 阈值由用户选。

## 统一字段口径（选品/商品信息域）

`amazon-research` 与 `product-info-search` 输出的列名共用下表规范名；各技能按自身数据输出列子集，不同语义字段（排名 vs BSR、配送费 vs FBA、尺码数 vs 变体数）保留为独立字段，不合并。

| 规范字段 | 定义 |
|---|---|
| 排名 | SERP 自然排名位 |
| BSR | 类目 Best Seller Rank |
| 标题 | 商品标题 / 产品名 |
| 品牌 | Brand |
| ASIN · 型号 | ASIN 或卖家型号 |
| 规格 | 规格描述 |
| 尺码数 | 可选尺码数 |
| 变体数 | 变体数量（含颜色/尺码） |
| 评分 | 星级评分 |
| 评论数 | 评论数（同「评价数」） |
| 月购买 | 月购买量；近似值须在备注标「代理指标」（同「月销」） |
| 售价 | 当前售价（口径：正常 Buy Box，非 Deal；同「当前价」） |
| 市场价 | 划线价 / List Price（同「参考价」） |
| 配送费 | 配送费 |
| FBA | 是否 FBA 履约 |
| 币种 | 币种（站点口径，不擅自换算汇率） |
| 上架日期 | 上架时间 |
| Buybox卖家 | Buy Box 卖家 |
| 链接 | 商品页 URL |
| 来源类型 | 官方 / 非官方 |
| 数据日期 | 快照抓取日期（与「上架日期」不同义） |
| 备注 | 来源 URL / 代理指标标注等 |
