# 产品信息搜索

只靠 **web_search** + **web_fetch** + Office JS 写表/格式/公式。**不**调用付费 API、CLI 或 user.* 脚本。缺数据标 **未能获取** 或 **未获取**，**绝不编造**。

## 用途

| 模式 | 何时 | 产出 |
|---|---|---|
| **单品快照**（默认） | 用户给产品名 / ASIN / 平台，或未指定时自动选热门品 | 新表 `产品信息_<简称>`，两列字段块 + 来源列 + 局限性说明 |
| **电商分析**（用户明确要求时） | Best Seller 榜单、批量 ASIN、跨平台比价、月销/BSR 对比 | 新表 `产品分析_<主题>`，一行一 SKU；拿不到的真实指标用 **代理指标** 或 **未获取** |

- 未指定查询目标时：自动选一个搜索索引较全的热门产品（如 Echo Dot），**值列**与 **备注** 标「技能自动选择」。
- 🔴 **定时监控、自动翻页、登录验证码**：现有算子做不了 → 引导 **取数栏** 或人工。
- 原 sorftime 类能力已**并入本技能**的「电商分析」模式，仍只走公开网页，不冒充 API 真值。

## 六步流程（单品快照 · 🟢）

### 第 1 步：说明抓取限制（对话，先不写表）

用中文简短告知：

- 只用网页搜索 + 本机 fetch；Amazon 商品页常 **403**，实时价/评分可能拿不到。
- 拿不到就标 **未能获取**，不编 ASIN、价格、评分。
- 要挂牌价/登录后数据 → 任务窗格 **取数栏** 跟手打开商品页。

### 第 2 步：定向搜索官方来源

1. **inspect_workbook**：看当前簿；空簿也可直接写新表。
2. **web_search**：
   - **优先**官方商品页：`amazon.com` / `amazon.ca` / `amazon.de` 等 **`/dp/`** 路径、品牌官网、`walmart.com/ip/`。
   - **其次**才可第三方（SERP 预览、比价站）；须在 **来源** 列标 **非官方**。
   - 记录：title、url、站点；从 URL 解析 ASIN（`/dp/` 后 10 位）。

**web_fetch**（每个 amazon `*/dp/*` URL **最多 1 次**）：

- 403 / 401 / error → **禁止**再抓同一 URL；用户说「继续」也 **禁止**重复 inspect + fetch 循环。
- 成功则从正文提取能确定的字段。

### 第 3 步：提取产品字段

按站点填值；**币种必须与站点一致**（写在字段名或值里）：

| 字段 | 说明 |
|---|---|
| 产品名 | 搜索 title 或用户指定 |
| 品牌 | 正文或 title 推断；不确定 → 未能获取 |
| ASIN / 型号 | URL 或正文；未能解析 → 未能获取 |
| 规格 | 正文要点；无 → 未能获取 |
| 参考价 | 划线价 / List Price；无 → 未能获取 |
| 当前价 | 抓取价；403 → 未能获取。**amazon.com 用 USD，amazon.ca 用 CAD** |
| 评分 | 抓取；无 → 未能获取 |
| 评价数 | 抓取；无 → 未能获取 |
| 链接 | 官方商品页 URL |
| 数据日期 | 当天日期（YYYY-MM-DD） |
| 数据来源类型 | **官方** 或 **非官方** |

### 第 4 步：写入数据块

**算子顺序**（必须全部执行到写出新表）：

1. **write_to_sheet** — 新表名 `产品信息_<产品简称>`，`data` 为 **三列**（固定表头）：

   ```
   字段 | 值 | 来源
   ```

   - **来源列** = 原「单元格批注」的替代：**与值同批写入**，每行必填（URL、web_search、web_fetch 403、非官方站点名等）。**禁止**先写值后补来源。
   - 第三方数据的 **来源** 写站点名并标「非官方」。

2. **write_formula** — 在 **折扣率** 行（紧跟参考价、当前价之后插入）写活公式，例如当前价在 B7、参考价在 B6 时 B8：

   ```
   =IFERROR(1-B7/B6,"")
   ```

   参考价或当前价为「未能获取」/非数字时留空。禁止心算折扣贴死值。

3. **format_range**：
   - 表头 `A1:C1`：`bold:true`，`bgColor:#DDEBF7`
   - 价格行（参考价、当前价）：按站点 `numberFormat`（USD `"$#,##0.00"`，CAD `"[$CAD]#,##0.00"`，CNY `¥#,##0.00`）
   - 折扣率行：`numberFormat:"0.0%"`
   - 可选：`autoFit:true` 于 `A:C`；`freezeRows:1`

> **能力说明**：核心算子**不支持 Excel 单元格批注**；用 **来源列** 等价实现「每字段可追溯」。

### 第 5 步：加局限性说明行

在同一表 **write_to_sheet 已含** 或 **write_to_range** 追加（字段 | 值 | 来源）：

| 字段 | 值示例 |
|---|---|
| — 局限性 — | （分隔行，三列可合并说明） |
| 数据日期 | 2026-08-17 |
| 抓取限制 | Amazon 403 时价格/评分为未能获取 |
| 价格时效 | 仅反映抓取时刻，非实时报价 |
| 币种口径 | 如：USD（amazon.com） |

### 第 6 步：回读核对

1. **ensure_table**（`sheetName` = 新表名，`range` 含 A1:C 已用区域）→ 记下返回的 `tableName`。
2. **inspect_table**（上一步 `tableName`）：确认表头为「字段|值|来源」，样例行含来源与局限性段。
3. **inspect_formulas**（`range` 含折扣率单元格）：确认折扣为公式而非死值。
4. **set_active_sheet**（可选）：切到结果表。
5. 中文汇报：新表名、哪些字段未能获取、是否含非官方来源、是否建议取数栏补价。

**没有写出新表不算完成。**

## 电商分析模式（用户明确要求时 · 🟢/🟡）

触发词示例：Best Seller、批量 ASIN、榜单、跨平台比价、月销、BSR。

### 字段体系（列顺序建议）

`ASIN` · `Title` · `Brand` · `BSR` · `参考价` · `当前价` · `币种` · `月销` · `评分` · `评价数` · `Buybox卖家` · `FBA` · `变体数` · `上架日期` · `链接` · `来源类型` · `备注`

### 步骤差异

1. 第 1–2 步同前；榜单类先 **web_search** 拿 ASIN 列表（不超过 **10 个**，更多标 🟡 建议取数栏）。
2. 每个 ASIN：**web_fetch 最多 1 次** `/dp/`；403 则该行价格/评分为 **未获取**，**禁止**对同一 ASIN 重试。
3. **write_to_sheet** 宽表 `产品分析_<主题>`，一行一 SKU；**备注**列写来源 URL 或「非官方」。
4. **代理指标规则**（强制）：
   - API/ERP 专属数据（精确月销、Buybox 历史等）**拿不到**。
   - 可用公开近似时（如「4K+ bought in past month」徽章）→ **月销** 填近似并 **备注** 标 **代理指标**；**禁止**冒充真实销量。
   - 完全无公开信号 → **未获取**。
5. **format_range**：表头 `bgColor:#DDEBF7` + 加粗；价格列按 **币种** 列分别格式化。
6. **ensure_table** → **inspect_table** 回读；报写入行数与未获取列统计。

### 边界

- 🟡 跨平台比价：各站各 fetch 一次，币种分列，不擅自换算汇率。
- 🔴 定时监控、历史曲线、>10 ASIN 批量：说明限制，引导取数栏或用户自备 CSV 再 `/整形`。

## 禁止

- 编造价格、ASIN、BSR、月销、评分。
- Amazon `/dp/` 403 后重复 web_fetch 或「继续」空转。
- 把 web_search JSON / encrypted_content 贴进用户可见回复或整页 HTML 写进表。
- 用 write_to_range 覆盖已有公式格（折扣必须用 write_formula）。
- 假装有 Sorftime/Keepa 等 API 数据。
